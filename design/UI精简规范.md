# 角色工坊 UI 精简规范

2026-11-07。React + Tauri Windows 桌面端。

## 方向

角色创作工作台。沿用翡翠绿品牌，视觉重点落在图片和操作上。图标用人物半身像、画框与创作笔表达“角色工坊”，不使用文字或字母。项目里的原始母版是 brand/charaforge-icon-master.png，生成工具与完整提示词见 brand/生成记录.json。

设计检索的第二轮匹配提供 Flat Design 建议，采纳简洁表面、少阴影、克制动效；检索中的营销页结构和新配色不适合当前桌面工具，不予采用。

## 色彩、字体与间距

- 底色 #F3F8F5，面板 #FFFFFF，主文字 #17372F。
- 品牌深绿 #0B5944，操作绿 #10955F，浅绿 #E1F6E9。
- Segoe UI / Microsoft YaHei，沿用用户字体缩放设置，不引入网络字体。
- 正文与输入以 12–13px 为主；主要按钮 38px、导航 44px，紧凑图标按钮保留明确标签和键盘焦点。
- 侧栏默认 168px；内容边距 16–18px，页面区块间距 12px。

## 布局

统一页头只保留页面名、核心状态与实际操作，去掉重复副标题。侧栏保留导航和反馈，品牌图标与中文名对齐。

生图页：角色工具栏 → 渠道页签 → 配置与预览。角色名称与项目选择为公共上下文。创建角色使用原生对话框，目录选项收进项目菜单。常用的角色、姿势和场景直接可见；表情、镜头、质量与输出设置按需展开。

配置和预览并排，配置独立滚动，生成按钮固定在配置区底部。预览优先占用约六成宽度，窗口高度分配使用 flex/grid，反馈信息出现时自动让出空间。生成中保留上一次结果，失败保留输入与结果。全屏查看采用原生 dialog，支持焦点约束和 Escape。

首页保留图库、扫描任务、最近结果；去掉与页头重复的数据库状态，快捷入口使用紧凑按钮。设置分类保留名称，把重复摘要改为提示信息，功能字段说明仍保留。

角色识别：顶部单行操作栏，扫描参数按需展开；主画布随剩余空间伸缩，缩略图条位于底部，角色复核为窄侧栏。画布按实际图像比例计算标注位置，横竖图切换保持框与图片对应；图例、坐标和个人模型详情收起。

相似计算：参数、分组筛选、图片列表和底部处理栏分层。图片使用自适应并排卡片，预览高度随窗口伸缩；保留、隔离、删除直接可操作，文件信息和分组次要操作折叠。处理栏参与布局，不能遮住末尾图片。

设置：运行环境与界面显示分栏，识别、生图及模型配置沿用同一绿色组件样式。CUDA、任务优先级和模型缓存目录默认折叠；保留真实状态、错误和必要字段说明。ComfyUI 安装目录必须可查看、选择和保存。

识别画布、缩略图、相似图与生图结果共用图片预览对话框，统一绿色标题栏、最大化可用图像面积、键盘焦点和 Escape 关闭。

## 动效与可访问性

启动动画为浅绿底上的角色卡片展开和品牌图标淡入，使用 transform/opacity，细进度轨道表示等待，不显示虚构百分比，也不增加固定等待时间。减少动态效果模式下停止装饰动画。

保留明确错误、表单标签、图标按钮名称及 focus-visible。折叠通过原生 details/summary，弹窗通过 dialog 实现。最小桌面窗口 1024×680，检查所有主页面的横向溢出和操作可达性。

## 范围

已调整公共框架、启动、品牌资源、首页、生图页，以及角色识别、相似计算和设置页的内部布局。保持已有 API、订阅、ComfyUI、识别、训练和存储协议。

本次内部布局验证使用隔离目录中的预置识别/相似结果，通过真实桌面程序和原生 IPC 检查标注绘制、撤销重做、全屏、处理选择及设置保存；未执行新的模型推理。验证记录位于 validation/internal-layout-20261107。
