# 统一领域与接口 v0.1

本文件为实施约束，尚无运行中的融合后端。

## 领域

| 对象 | 关键字段/边界 |
|---|---|
| Project | project_id, root, module_paths, schema_version |
| Character | character_id, canon_tag, display_name, aliases；原著身份 |
| CoserIdentity | coser_id, reference_asset_ids, appearance_rules；演员脸与角色分开 |
| CostumeVariant | costume_id, character_id, garment_rules, reference_asset_ids |
| Asset | asset_id(UUID), project_id, current_version_id, intended_character_id；稳定业务身份 |
| AssetVersion | version_id, asset_id, parent_version_id, sha256, path, width, height, provenance_id；返修是新版本 |
| GenerationReview | version_id, status(pending/passed/repair), actor, rule_version, observations, evidence, reason |
| Recognition | version_id, detection_id, model_id, domain, scores, review_status；人物框可有多个 |
| SimilarityRelation | left/right_version_id, kind, algorithm_version, score, confirmation；没有写生成审核状态的权力 |
| RequestSnapshot | prompt_modules, effective_prompt, engine_payload, reference_hashes/order, masks, model/template/LoRA/version/seed |
| DatasetVersion | items(version_id/hash/caption), source_split, dedupe_report, coverage, frozen_at |
| TrainingRun | dataset_version_id, base_model_hash/family, trainer, config, output/hash, logs, evaluation |

禁止把文件路径、内容哈希、人物检测框和业务资产 ID 当成同一个东西。一个文件中可以有多个角色；一个 asset 有多次返修版本；文件移动不会重新创建身份。

## Worker envelope

```json
{
  "protocol_version": 1,
  "request_id": "uuid",
  "task_id": "uuid",
  "project_id": "uuid",
  "type": "request",
  "method": "generation.submit",
  "params": {"snapshot_id": "uuid", "engine_id": "comfy-local"}
}
```

响应带同样的 request/task/project 标识，type 为 progress/result/error；error 为 code/message/retryability/details。不返回密钥；项目上下文校验失败不执行。取消是独立 request，不靠停止读取日志实现。

## Engine capabilities

每个 engine + model + workflow 组合返回 supports_text/reference_images/mask/pose_control/negative_prompt/seed/job_query/cancel/max_refs/sizes；字段值可为 true/false/unknown。ComfyUI 按模板判断，不能只按服务在线判断。请求发送前 validate(snapshot, capabilities)；未知能力须先测试或明确用户选择，不能静默丢字段。

## 共用工具

只读：project.inspect、catalog.list/get、assets.list/get、experience.search、engines.capabilities、jobs.status、training.status。

写任务：plan.save、generation.submit、review.run、repair.prepare/submit、dataset.freeze、training.start/cancel、recognition.scan、similarity.scan。

正式文件操作：review.decide、asset.apply_candidate、classification.preview/commit、archive.restore。入口必须绑定版本哈希、权限与确认记录；Agent 不通过任意 shell 拼接执行文件操作。

## 提示词编译

同一 PromptBundle 可编译成 cloud 文本或 ComfyUI 节点参数，二者最终传输不保证相同字节。保存 source bundle 和实际编译结果；不承诺同样角色模块跨引擎随机生成同一张图。

已有图片审核始终作用于具体 version_id。用户已审核、候选替换、源文件外部变更时，旧观察不能继续给新版本盖已通过标签。
