# 融合界面规范

品牌：角色工坊 / CharaForge。浅色工作界面，海青主色、冰蓝选中底色、白与浅灰底、深色中文正文；保留旧工作台 B 版清晰三栏、大预览的优点，与 anime-pic-manage 的薄荷风格融合。

## 主空间

窄导航（约 160–180px 可调）+当前工作内容+预览。生成页面只有这三个常驻空间。审核可将内容分成队列/证据，但不再增加固定底部大卡片。导航和分栏有最小宽度，窄窗口收起辅助信息；内容自适应，无页面横向滚动。

图片全屏在右上角；备选、原始请求、蒙版编辑、相似对比、日志详情用大弹窗。字体 Microsoft YaHei / Segoe UI，中文完整，所有可勾选项显示勾号。每个远端请求都有进度与错误出口；按钮执行中只锁相关动作，保留取消和切换查看。

## 三张设计图

1. 生图工作台：引擎切换、模块、参考、复制最终提示词和大预览。
2. 审核返修：按角色队列、原图与返修候选、局部证据、复制返修提示、接收入库。
3. 训练中心：LoRA / 识别学习分开，已通过数据、去重与覆盖、训练配置、固定种子评估。

图中数量、模型配置和性能展示仅为示例。图像可能有中文文字误差或细节布局问题，开发以本规范为准。参考缩略图不是新角色标准，也不替换用户原衣装参考。

这些图片通过用户指定的新接口 `https://www.newtransfer.site/v1` 请求模型 `gpt-image-2`，使用 imagegen 自带 CLI，请求尺寸 2048x1152、quality=high。实际返回三张均为 1672x941，已用 Pillow 读取验证，不将请求尺寸当作实际输出尺寸。完整输入在 `design/prompts`。本阶段不向接口上传角色图库、原项目源码或任何账号配置，仅发送 UI 设计提示词。
