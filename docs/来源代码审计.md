## 必须解决的融合冲突

1. Tauri 与 Qt 两套 UI、Python 全局 ROOT 与单窗口多项目切换。
2. Rust 图片/标注表与 Agent 任务/候选 JSON、SQLite 两套资源 ID。
3. 三类生成审核状态，与识别置信/人工矫正状态不能混为一个字段。
4. 本地优先与云端上传：图库扫描和训练保持本地；用户选择云端生图/视觉时，只提交本次声明的参考和待审图。
5. 动漫角色识别、cosplay 身份一致性、精确重复、感知相似、人体质量是不同问题。
6. GPU 训练、ComfyUI 和本地识别会竞争显存，需要可取消的资源调度和明确的等待原因。
7. LoRA 家族、底模哈希、模板节点能力都要检查，不能只按文件名猜测兼容性。
